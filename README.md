# Portfolio de Nicolás Pereyra Pigerl

Portfolio técnico y CV de un estudiante de Ingeniería Electrónica (UTN FRBA): electrónica de potencia, sistemas embebidos y automotriz.

Sitio estático (HTML, CSS y un poco de JavaScript), sin dependencias de compilación. Cada proyecto se cuenta como una nota de blog.

- `index.html`: portada, notas y línea de tiempo
- `cv.html` y `CV_Nicolas_Pereyra_Pigerl.pdf`: currículum
- `posts/`: una nota por proyecto
- `assets/`: imágenes y diagramas
